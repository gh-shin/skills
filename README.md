## 설치

저장소의 `report-polish` 디렉터리를 사용하는 에이전트의 사용자 스킬 폴더로 복사하세요. Codex에서는 `~/.agents/skills/report-polish/SKILL.md`에 둘 수 있습니다.

## 사용 예시

```text
$report-polish 아래 글을 사실·수치·조건을 유지하면서 개조식 보고서로 정리해 주세요.

[원문]
여기에 정리할 원문을 입력하세요.
```
