# 시나리오 기록과 실행 판정

조사와 실행 검증에서 같은 시나리오 목록을 사용한다. 결함 목록에만 의존하면 정상
동작이나 미구현 흐름이 빠질 수 있으므로 선정 범위 전체를 목록에 남긴다. 작은
범위는 아래 정보를 한 표에 담고, 큰 범위는 저장소의 기존 기록 형식을 사용한다.

## 실행 전에 기대 동작을 고정한다

| 정보 | 필요한 내용 |
| --- | --- |
| ID·목표·근거 | 안정된 시나리오 ID, 사용자 목표, 기대 동작의 요구사항·계약·사용자 지시 근거 |
| 사전 상태·데이터 | 실행에 필요한 상태와 사용이 허용된 데이터 |
| 입력 순서 | 사용자 입력과 기다림·취소 등 결과에 영향을 주는 순서 |
| 관찰·기대값 | 화면·응답, 저장·재조회 결과 중 관련된 것의 기대 내용·최종 상태와 금지된 결과 |
| 실행 증거·판정 | 실행 환경, 명령·로그·캡처 등 근거, 실행 상태와 제한, 연결된 발견 사항 ID |

정상·실패·취소/재시도·재시작·응답 역전 조건은 해당 위험이 있을 때 선정한다.
모든 조합을 요구하지 않는다. 후속 감사나 재실행에서도 같은 ID를 유지한다.

기대 동작의 근거가 없거나 계약이 충돌하면 현재 구현을 정답으로 삼지 않는다.
확인이 필요한 계약과 판정할 수 없는 범위를 기록하고, 알려진 부분은 계속 조사·
실행한다. 미구현 흐름도 삭제하지 않는다. 실행 상태는 아래 정의에 따라 기록한다.

## 성공 조건이 실제로 실패를 잡는지 확인한다

기대 결과가 존재하고 내용과 최종 상태가 맞는지 먼저 확인한다. 금지된 결과가
없는지도 함께 확인한다. 결과의 부재만 검사하면 빈 출력도 통과할 수 있다.

완료·성공 표시가 다음 사용자 동작의 기준인 계약은 그 관찰 신호와 실제 후조건의
순서까지 검증한다. 해당 신호를 기다린 뒤 다음 동작을 실행하며, 내부 저장이나
비동기 작업이 먼저 끝날 때까지 별도로 기다려 조기 완료나 상태 경쟁을 가리지 않는다.
시험 준비 데이터의 안정화 대기와 검증 대상 동작의 완료 대기를 구분한다. 장애 주입은
기존 OS callback·I/O·외부 서비스 경계에 한정하며, 모든 타이밍 조합이나 별도
단위테스트를 요구하지 않는다.

- 특정 항목이 있어야 하는 검색은 항목의 존재·내용도 검사한다. 이전 항목이
  없다는 검사만으로 빈 결과를 통과시키지 않는다.
- 필수 응답이나 저장값의 누락은 실패다. optional chaining이나 조건부 단언으로
  관찰 자체를 건너뛴 뒤 통과시키지 않는다.
- 이런 위험이 있는 판정에는 빈 값·누락·오래된 값 등 최소 반례를 넣어 실제로
  탈락하는지 확인하고 그 근거를 남긴다. 모든 검사에 별도 단위테스트나 변이테스트를
  추가할 의무는 없다. 검증할 핵심 로직을 대역으로 바꾸지 않는다.

## 실행 상태와 집계를 구분한다

| 상태 | 의미 |
| --- | --- |
| `PASS` | 실행 증거로 기대 결과의 존재·내용·최종 상태와 관련 금지 결과의 부재를 확인함 |
| `FAIL` | 유효한 실행·관찰로 제품의 기대 동작 위반을 확인함. 원인과 근거를 기록함 |
| `NOT_RUN` | 해당 시나리오를 실행하지 못했거나 실행하지 않음. 계약 미확정이나 준비 실패로 제품 동작에 도달하지 못한 경우도 포함 |
| `UNVERIFIED` | 실행했지만 기대 계약·관찰·최종 증거가 부족하거나 충돌하여 판정할 수 없음 |

실행 환경·준비 실패 자체는 제품 결함의 증거가 아니다. 제품 경로에 도달했는지와
어떤 관찰이 부족한지로 `NOT_RUN` 또는 `UNVERIFIED`를 정하고 원인을 기록한다.
잘못된 테스트 가정 때문에 기대 동작 위반을 확인할 수 없으면 `UNVERIFIED`로 남긴다.
코드 검토의 `ACCEPT`와 실행 `PASS`를 서로 대신하지 않는다.

보고 시 각 ID의 최종 상태를 위 네 상태 중 하나로 정하고, 선정한 고유 시나리오
수를 분모로 상태별 수를 집계한다. 실행 시도와 재실행은 별도 횟수로 기록하며 이전
실패 근거를 보존한다. 여러 입력을 하나의 시나리오로 묶었다면 필요한 입력의 결과가
모두 확인돼야 `PASS`다. 선정 범위의 결과를 전체 앱 커버리지로 확대하지 않는다.
